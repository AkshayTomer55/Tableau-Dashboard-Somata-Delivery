# 📊 Food Delivery Sales Dashboard (Tableau)

🚀 This dashboard visualizes food delivery performance metrics across 7 days in October 2023.  
Built using **Tableau**, it helps stakeholders understand:
- Order trends
- Customer behavior
- Top-selling food items
- Delivery agent performance

---

## 🎯 Key Features
- 📈 KPI Cards: Total Order Value, Total Orders, Average Order Value
- 🍔 Top 3 Food Items: Dynamic Ranking
- 📊 Trendline Charts: Daily Order Trends
- 👥 Customer & Delivery Agent Leaderboards
- 📌 Bar Charts: Food Item–wise Revenue Comparison

---

## 🛠 Tools & Data
- **Built With**: Tableau Desktop
- **Data Source**: Cleaned CSV (Simulated for Training Use)
